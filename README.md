### [Distributed Subscription System](https://github.com/atlasmarsaren/Distributed-Subscription-System-Application)
A Java client-server learning project with three servers, TCP sockets and timestamp-based state synchronisation. Includes a command-line client, local setup instructions and a [video walkthrough](https://youtu.be/NqTfXU1jL_c).
